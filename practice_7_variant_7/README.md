# Практическая работа 7 — вариант 7

Первое полноценное ООП-приложение. Корпоративный заказ оборудования.

Программа формирует заказ для сотрудника: добавляет товары, объединяет повторные позиции по id, удаляет позиции и вычисляет итоговую стоимость. Цена товара должна быть положительной. После подтверждения состав и количество позиций изменить нельзя.

Для варианта 7 количество одной позиции ограничено диапазоном от 1 до 40 включительно. Ограничение проверяется и после объединения повторного товара. Максимум хранится в `OrderItem.MAX_QUANTITY`.

Сборка без Maven — нужен JDK 17 или новее

```bash
mkdir -p out
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out ru.edu.pr04.SelfCheck
```

Запуск программы

```bash
java -cp out ru.edu.pr04.Main
```

Сначала вводятся id и ФИО сотрудника, затем команды: `add id;name;price;quantity`, `remove id`, `show`, `confirm`, `exit`. Например, `add M01;Monitor;32990;2` добавляет два монитора. Дробная цена записывается через точку.

Команды выполняются из папки `practice_7_variant_7`. Для загрузки примеров используется `java -cp out ru.edu.pr04.Main --file data/sample.csv`. При загрузке файла корректные строки добавляются, ошибочные получают сообщение; заказ остаётся черновиком. `SelfCheck` проверяет границы, объединение, удаление и защиту подтверждённого заказа.
