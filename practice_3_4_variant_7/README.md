# Практическая работа 3–4 — вариант 7

Расчёт стоимости заказа с учётом скидки и НДС.

Программа получает количество товара, цену за единицу и скидку. После проверки данных вычисляет базовую стоимость, сумму после скидки, НДС и итоговую стоимость заказа. Допустимы количество от 1 до 10000, цена от 0.01 до 5000000 и скидка от 0 до 30%.

Для варианта 7 ставка НДС равна 40%. Она хранится в константе `OrderCalculator.VAT_RATE` и применяется к сумме после скидки.

Сборка без Maven

```bash
mkdir -p out
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out ru.edu.pr01.SelfCheck
```

Запуск программы

```bash
java -cp out ru.edu.pr01.Main
```

Команды выполняются из папки `practice_3_4_variant_7`. Дробные числа при вводе записываются через точку. `SelfCheck` проверяет расчёты и допустимые границы входных данных.
