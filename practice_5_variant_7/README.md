# Практическая работа 5 — вариант 7

Строки, массивы, циклы и методы обработки данных

Программа обрабатывает табель сотрудника за пять рабочих дней. Входная строка содержит пять целых значений от 0 до 16, разделённых точкой с запятой. По ним вычисляются сумма и среднее часов, количество дней с переработкой и недельная переработка. Ошибка одного значения отклоняет весь табель; сообщение указывает позицию ошибочного дня.

Для варианта 7 дневная норма равна 40 часам, недельная — 40 часам. При допустимом вводе 0–16 дней с переработкой нет, но недельная переработка возможна и равна `max(0, сумма - 40)`.

Сборка без Maven

```bash
mkdir -p out
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out ru.edu.pr02.SelfCheck
```

Запуск программы

```bash
java -cp out ru.edu.pr02.Main
```

Пример входной строки: `9;8;7;10;8`. Результат: сумма 42, среднее 8.4, дней с переработкой 0, недельная переработка 2 часа.

Команды выполняются из папки `practice_5_variant_7`. Для обработки примеров из файла используется `java -cp out ru.edu.pr02.Main --file data/sample.csv`. `SelfCheck` проверяет расчёты, границы и ошибки разбора строки.
