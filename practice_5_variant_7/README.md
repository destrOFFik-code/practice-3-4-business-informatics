# Практическая работа №5 — вариант 7

Строки, массивы, циклы и методы обработки данных. Программа анализирует табель одного сотрудника за пять рабочих дней. Структура сохранена по примеру `practice5`: пакет `ru.edu.pr02`, `TimesheetAnalyzer`, `SelfCheck`, данные, диаграммы и `DECISIONS.md`. Дополнительно есть консольный класс `Main`.

## Правило варианта 7

В таблице задания вариант 7 изменяет **норму часов в день на 40**. Поэтому `DAY_NORM = 40`, а день считается переработкой при `hours[i] > DAY_NORM`. Остальные правила сохраняются: ровно пять целых значений от 0 до 16, недельная норма 40 часов.

Параметр 40 применяется как значение нормы: в условии нет указания на проценты или прибавление к исходной норме. При диапазоне 0–16 ни один допустимый день не превышает 40 часов, поэтому дневная переработка всегда равна 0. Недельная переработка считается отдельно и может быть положительной. Например, `9;8;7;10;8` даёт сумму 42, среднее 8.4, 0 дней с переработкой и 2 часа недельной переработки.

## Сборка и самопроверка

Нужен JDK 11 или новее, без Maven и сторонних библиотек. Проверено на OpenJDK 21.

Из этой папки:

```bash
bash run_selfcheck.sh
```

Или вручную:

```bash
mkdir -p out
javac -encoding UTF-8 -d out src/ru/edu/pr02/*.java
java -cp out ru.edu.pr02.SelfCheck
```

Для Windows предусмотрен `run_selfcheck.bat`.

## Запуск программы

Ввод одной строки с клавиатуры:

```bash
bash run.sh
```

Строка в аргументе (кавычки обязательны из-за точек с запятой):

```bash
bash run.sh "9;8;7;10;8"
```

Обработка всех строк файла:

```bash
bash run.sh --file data/sample.csv
bash run.sh --file data/boundary.csv
```

После ручной сборки также можно запускать `java -cp out ru.edu.pr02.Main`. В режиме файла некорректная строка получает сообщение об ошибке; затем обрабатывается следующий табель. Частичный отчёт для некорректного табеля не выводится.

Пример результата для `9;8;7;10;8`:

```text
Часы по дням: [9, 8, 7, 10, 8]
Всего часов: 42
Среднее за день: 8.40
Дней с переработкой (более 40 ч): 0
Недельная переработка (сверх 40 ч): 2
```

## Материалы работы

- `src/ru/edu/pr02/TimesheetAnalyzer.java` — разбор и четыре вычислительных метода исходного проекта.
- `src/ru/edu/pr02/Main.java` — ввод строки, запуск расчётов и отчёт.
- `src/ru/edu/pr02/SelfCheck.java` — собственные проверки с выводом PASS/FAIL и ненулевым кодом завершения при провале.
- [diagrams.md](diagrams.md) — завершённые Activity-диаграмма и диаграмма классов в Mermaid, как в примере на GitHub.
- [REPORT.md](REPORT.md) — анализ ошибочного цикла, индивидуальное правило и ответы на вопросы задания.
- [CHECKS.md](CHECKS.md) — результаты граничных проверок.
- [DECISIONS.md](DECISIONS.md) — два принципиальных решения.

Проверки выполняются обычными циклами и методами; Stream API не используется. Вычислительные методы принимают готовые массивы, а проверку структуры и диапазона входного табеля выполняет `parseHours`. `Main` вызывает вычисления только после успешного разбора.
