# Решения

1. Дневная норма варианта 7 хранится в `TimesheetAnalyzer.DAY_NORM = 40`. Метод `overtimeDays` использует строгое сравнение `> DAY_NORM`. Верхняя граница ввода `MAX_HOURS = 16` и недельная норма `WEEK_NORM = 40` являются самостоятельными правилами. Изменение дневной нормы требует изменения одной константы; `Main` получает значение нормы для отчёта из того же класса.

2. Табель разбирается целиком до любых расчётов. `parseHours` сохраняет пустые элементы через `split(";", -1)`, проверяет количество значений, целочисленный формат и диапазон каждого дня. При ошибке выбрасывается `IllegalArgumentException` с позицией от 1, а `Main` выводит сообщение вместо частичного результата. Для ошибки структуры сообщается ожидаемое и полученное количество значений.
