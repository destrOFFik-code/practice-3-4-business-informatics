# Практическая работа 6 — вариант 7

Небольшая логическая задача с ветвлениями и конечным набором решений

Программа выбирает маршрут согласования заявки по сумме, срочности, уровню риска и наличию персональных данных. Проверки выполняются по приоритету: персональные данные → `SECURITY_REVIEW`, высокий риск → `DIRECTOR_REVIEW`, достижение финансового порога → `FINANCE_REVIEW`, срочная заявка ниже порога → `FAST_TRACK`. В остальных случаях выбирается `STANDARD`.

Для варианта 7 финансовый порог равен 40 и хранится в `ApprovalRouter.FINANCE_LIMIT`. Сумма 40 уже требует финансового согласования, если раньше не сработали правила персональных данных или высокого риска.

Сборка без Maven

```bash
mkdir -p out
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out ru.edu.pr03.SelfCheck
```

Запуск программы

```bash
java -cp out ru.edu.pr03.Main
```

Формат строки: `amount;urgent;risk;personal`. Сумма — неотрицательное целое число, логические признаки — `true` или `false`, риск — `LOW`, `MEDIUM` или `HIGH`. Например, `39;true;LOW;false` даёт `FAST_TRACK`, а `40;true;LOW;false` — `FINANCE_REVIEW`.

Команды выполняются из папки `practice_6_variant_7`. Для обработки примеров из файла используется `java -cp out ru.edu.pr03.Main --file data/sample.csv`. `SelfCheck` проверяет границы суммы, приоритет пересекающихся условий и ошибки ввода.
