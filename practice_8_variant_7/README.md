# Практическая работа 8 — вариант 7

Инкапсуляция, enum и управление состоянием объекта.

Программа оформляет командировки и управляет их состояниями: DRAFT, SUBMITTED, APPROVED, REJECTED, CANCELLED и COMPLETED. Статус изменяется операциями `submit`, `approve`, `reject`, `cancel` и `complete`. Проверяются обязательные данные, календарные даты и допустимость каждого перехода; ошибка сохраняет прежнее состояние заявки.

Для варианта 7 причина отклонения должна содержать минимум 40 символов после удаления крайних пробелов. Ограничение хранится в `BusinessTrip.MIN_REJECTION_REASON_LENGTH`. Завершить можно только одобренную командировку и строго после даты её окончания.

Сборка без Maven — нужен JDK 11 или новее

```bash
mkdir -p out
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out ru.edu.pr05.SelfCheck
```

Запуск программы

```bash
java -cp out ru.edu.pr05.Main
```

Команды: `create id;start;end`, `submit id`, `approve id`, `reject id;причина`, `cancel id`, `complete id`, `show id`, `list [STATUS]`, `exit`. Даты вводятся в формате `YYYY-MM-DD`. Например, `create T1;2026-10-10;2026-10-12` создаёт черновик. Для завершения используется текущая дата по Москве.

Команды выполняются из папки `practice_8_variant_7`. Для обработки примеров используется `java -cp out ru.edu.pr05.Main --file data/sample.csv`. Повторные строки с одним id выполняют следующие операции над той же заявкой; даты должны совпадать. `SelfCheck` проверяет все 30 сочетаний состояния и операции, граничную длину причины и календарные ошибки.
